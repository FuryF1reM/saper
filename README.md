# Опис

Класична гра «Сапер», реалізована на C#. Містить вибір рівня складності, можливість налаштування власних параметрів, таймер гри та кнопку виходу.

# Функціонал

## Рівні складності:

  -Легкий
  
  -Середній
  
  -Складний
  
  -Кастомна складність:
  > Налаштування розміру поля
  > 
  > Вибір кількості мін

## Таймер:

- Автоматично запускається при старті гри

- Відображає час проходження
## Ігрова логіка:

> Відкриття клітинок
> 
> Встановлення прапорців
> 
> Перевірка перемоги/поразки
> 
## Інтерфейс:
- Зручне меню вибору
  
- Кнопка виходу з гри
## Характеристики
- Мова: C#

- Графічний двигун: Unity
  
## Запуск
1. [Завантажити реліз](https://github.com/FuryF1reM/saper/releases/)
   
2. Запустити
   
3. Вибрати складність
   
4. Грати

## Керування
> Ліва кнопка миші — відкрити клітинку
> 
> Права кнопка миші — встановити/зняти прапорець

## Мета гри

Відкрити всі клітинки без мін, використовуючи підказки (числа), що показують кількість мін поруч.

## Вихід з гри  
Для завершення використовуйте кнопку «Вихід» у меню.
